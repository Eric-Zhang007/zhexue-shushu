# 紫微斗数匹配文墨天机格式

ziwei.py 支持与文墨天机一致的文本输出格式。

## 用法

```bash
python3 ziwei.py <年> <月> <日> <时> <分> <男/女> [--longitude 经度]
```

输出: JSON + 树形文本命盘 (格式参考 `references/wenmo-tianji-format.md`)

## 紫微斗数模块清单

### 安星诀
- 命宫/身宫: 标准逆月顺时公式
- 十四主星: 紫微系6+天府系8 (生日÷局数定位)
- 辅星: 左辅右弼文昌文曲天魁天钺禄存擎羊陀罗火星铃星天马
- 小星: 39颗 (年支/月支/时支/年干定位)
- 五行局: 命宫干支纳音定局

### 庙旺利陷
- 26星×12宫 亮度表 (MIAO_WANG_LI_XIAN)
- 等级: 庙>旺>得>利>平>不>陷

### 四化系统
- 生年四化: 年干定 (SIHUA_TABLE)
- 自化: 宫干飞四化→本宫(↓离心)/对宫(↑向心)
- 两者可叠加 → 如 巨门[生年忌][↓禄]

### 神煞 (紫微专用,4套)
- 岁前星(13): 年支起岁建顺循环
- 将前星(12): 年支三合起将星顺循环
- 十二长生: 命宫起病逆时针
- 太岁煞禄(博士12神): 禄存位起博士顺/逆

### 大小限
- 大限: 每宫10年, 命宫起始岁=局数, 阳男阴女顺/阴男阳女逆
- 小限: 命宫起1岁逆时针, 12年周期
- 流年: 命宫起1岁逆时针, 12年周期
- 限流叠宫: 大限+流年是否重合到特定宫位

## 关键数据表位置
均在 zhexue_core.py 中:
- MIAO_WANG_LI_XIAN: 庙旺利陷表
- JU_NAMES: 五行局中文名
- MING_ZHU_TABLE / SHEN_ZHU_TABLE: 命主身主
- 39个star_*()函数: 小星定位
- get_suiqian/get_jiangqian/ziwei_shier_changsheng/get_taisui_shalu: 神煞
