# 梅花易数 + 八字交叉验证方法论

适用于问人际/关系/态度类问题：梅花易数抓"当下、具体"，八字看"本质、格局"。

## 一、何时用梅花易数 vs 八字

| 场景 | 用哪个 | 原因 |
|------|--------|------|
| 对方性格/格局 | 八字 | 八字看人固化的秉性 |
| 对方目前对我的态度 | 梅花易数 | 态度是动态的，起卦抓当下 |
| 关系未来走向 | 两者结合 | 梅花易数抓趋势(变卦)，八字看两人五行适配 |
| 对方在做什么/瞒什么 | 梅花易数 | 用卦象象意+变卦指向推断 |

## 二、梅花易数解读原则

### 2.1 本卦 → 现状
- 本卦=对方当下的状态/态度
- 动爻=关键信息点：看爻辞 + 看动的位置(初爻=开始端, 上爻=结果端)
- 不能用纯卦辞翻译，要结合具体生活场景

### 2.2 体用生克 → 关系本质
- **体卦** = 问卦人（我）
- **用卦** = 对方/事情
- 用生体 = 大吉（对方滋养我/事情对我有利）
- 体克用 = 大吉（我能掌控/我能看得穿）
- 体生用 = 凶（我在消耗自己）
- 用克体 = 大凶（对方/事情在伤害我）
- 比和 = 小吉（旗鼓相当，平局）

### 2.3 变卦 → 结果/趋势
- 变卦=这件事情的最终走向
- 对比本卦→变卦的变化方向：从遁到同人=从隐瞒到坦荡

### 2.4 互卦 → 过程
- 本卦的互卦=这个阶段中间经历什么
- 同一问题多次起卦，互卦重复出现是强信号

### 2.5 八卦象意（人际类关键象）
- 乾☰ = 领导、权威、主动方（金）
- 坤☷ = 承载、包容、被动方（土）
- 震☳ = 变动、行动、崛起（木）
- 巽☴ = 入、渗透、信息流动、无形技术（木）
- 坎☵ = 险、陷、困境、深藏（水）
- 离☲ = 明、火、热情、光明、文章（火）
- 艮☶ = 止、藏、隐瞒、保留（土）
- 兑☱ = 口、说、沟通、喜悦（金）

## 三、八字对比分析流程

### 3.1 逐项罗列对比

两人八字要按以下维度逐项对比：

1. **日主**：五行+身旺/身弱 + 月令格局
2. **用神忌神**：完全相反还是互补
3. **天干十神**：看两人相处模式
4. **地支藏干**：看隐藏的性格
5. **神煞**：华盖/太极/文昌等看精神层面是否匹配
6. **大运节奏**：谁的黄金期在前面，谁在后面

### 3.2 互动模式判断

- 甲木克戊土 = 一方约束另一方
- 乙木生丙火 = 一方输出想法，另一方接收/跟随
- 同为丙火/同为乙木 = 竞争/较劲
- 劫财透月 = 朋友间的竞争心强
- 互相是对方的用神 = 相处舒服
- 互相是对方的忌神 = 天然摩擦

### 3.3 人生节奏对比

关键看大运的五行流向：

- **早早起运+顺排+好运在前半段** = 少年得志
- **起运晚+逆排+好运在后半段** = 大器晚成
- 用"早甜晚平" vs "先苦后甜"的框架输出

## 四、输出格式

两人对比推荐表格对比：

| 维度 | 甲 | 乙 | 对比结论 |
|------|---|---|---------|
| 日主 | 乙木身弱 | 丙火身旺 | 完全相反|
| 格局 | 七杀格 | 建禄格 | 一杀一禄 |
| 用神 | 水木 | 金水 | 水是共同交集|
| 聪明类型| 内敛深沉 | 外放发散 | 互补|
| 黄金期 | 46+ | 26-45 | 节奏错开|

（以上为示例对比，非真实个人命盘）

梅花易数解读最后要：**卦上分析 + 八字验证 + 具体场景推断** 三段结构。
