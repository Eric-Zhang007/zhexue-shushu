## 一、格局判定流程

### 1.1 月令取格

取月支藏干的主气（第一个藏干）定格局：

```python
from zhexue_core import DI_ZHI, ZHI_CANG_GAN, TIAN_GAN, get_shi_shen

月支索引 = DI_ZHI.index(yue_zhi)
主气索引 = ZHI_CANG_GAN[月支索引][0]
格局 = get_shi_shen(日干索引, 主气索引)
# → "七杀格"、"正官格"、"正印格"等
```

### 1.2 格局分类

| 格局 | 十神 | 五行关系 | 性格特征 |
|------|------|---------|---------|
| 七杀格 | 七杀 | 克我且阴阳同 | 抗压、不服、越压越强 |
| 正官格 | 正官 | 克我且阴阳异 | 守规矩、责任心强 |
| 正印格 | 正印 | 生我且阴阳异 | 好学历、安稳、贵人 |
| 偏印格 | 偏印 | 生我且阴阳同 | 偏才、冷门领域 |
| 正财格 | 正财 | 我克且阴阳异 | 稳定财、踏实 |
| 偏财格 | 偏财 | 我克且阴阳同 | 大财、敢闯 |
| 食神格 | 食神 | 我生且阴阳同 | 才华温和展现 |
| 伤官格 | 伤官 | 我生且阴阳异 | 才华激烈、叛逆 |
| 比肩/劫财格 | 比劫 | 同我 | 合作、竞争 |

### 1.3 重点：七杀格 vs 正官格

同为"官杀格"大类，但差异巨大：

| 维度 | 七杀格 | 正官格 |
|------|--------|--------|
| 压力性质 | 暴力克制 | 温和约束 |
| 应对方式 | 制（食伤）或化（印） | 承受即可 |
| 抗压能力 | 极高，越压越强 | 适中 |
| 人生节奏 | 大起大落 | 稳中有升 |
| 健康 | 易过劳/免疫高压 | 一般 |

## 二、七杀格用神体系（分层而非单一）

对七杀格的分析，**不能只给一个用神五行**。必须分层次解释。

### 2.1 身弱七杀格

```
第一用神: 印(水) → 化杀生身
  原理: 金生水→水生木，杀星转化为生源
  核心逻辑: 不硬扛，转凶为吉

第二用神: 比劫(木) → 帮身抗杀
  原理: 增加日主力量，硬扛七杀
  副作用: 比劫生食伤→食伤生财→财生杀(间接帮倒忙)

第三用神: 食伤(火) → 以智制杀
  原理: 食伤制杀，以才华对抗压力
  问题: 身弱时食伤过于泄身，空有手段没有体力
```

**关键判断逻辑：** 身弱七杀格最优解是**印化杀**而非**食伤制杀**。虽然食伤直接制杀看起来更有效，但身弱时食伤泄身过度，反而耗损底子。印化杀是"把敌人的能量转化成自己的能量"。

### 2.2 身强七杀格

```
用神: 食伤(火) → 食伤制杀，直接有效
辅助: 财(土) → 财滋杀但有食伤制衡
忌神: 印(水) → 印化杀但身强不需要; 比劫(木) → 生食伤即可
```

### 2.3 常见的判断错误

- ❌ 脚本输出"用神木忌神金"就直接照搬 → 对于七杀格身弱，水(印)优于木(比劫)
- ❌ 只说一个用神五行 → 必须分层次（第一用神/第二用神/忌神）
- ❌ 说"以火制杀"而忽略身弱 → 身弱时制杀手段虽对但身体扛不住

## 三、食伤混杂在七杀格中的分析

### 3.1 什么是食伤混杂

天干同时透出食神和伤官（或地支同时有食神和伤官藏干），称为食伤混杂。

### 3.2 好坏两面的分析框架

**好的方面：**
- 制杀手段多样化 — 既有温和制杀（食神）又有激烈制杀（伤官）
- 才华全面 — 食神温和展现才华，伤官叛逆创新
- 有不循规蹈矩的能力

**坏的方面（对身弱尤其明显）：**
- 食伤都泄身 → 身弱更弱
- 内耗 — 两个不同声音在决策（食神想温和，伤官想莽）
- 想法多但执行力打折 — 被泄身过度，精力跟不上脑子
- 对身弱七杀格来说："有把好枪（食伤制杀），但端枪的手（身弱）在发抖"

### 3.3 分析框架

```python
判断:
  身强 + 食伤混杂 = 才华横溢、敢闯敢干
  身弱 + 食伤混杂 = 想法多、执行打折、需要印来支撑

建议:
  身弱食伤混杂 → 等水(印)运到来，食伤不燥且有根
  身强食伤混杂 → 直接用，食伤制杀是杀招
```

## 四、职业/学业轨迹映射（进阶分析）

### 4.1 核心映射表

| 现实要素 | 八字对应 | 分析维度 |
|---------|---------|---------|
| 研究产出/论文 | 食神/伤官 | 食伤旺=出活快、有创意 |
| 学历/文凭录取 | 正印/偏印 | 印旺=考试运好、学历顺 |
| 导师/贵人赏识 | 印 | 印星=贵人/师长 |
| 抗压/实验室搬砖 | 七杀 | 七杀格=高压下反出活 |
| 奖学金/收入 | 正财/偏财 | 财运=经济保障 |
| 名校/GPA | 印 + 官 | 官印相生=传统学术路顺 |

### 4.2 PhD申请的分析框架

```
PhD三要素 ↔ 八字三支柱:

1. 研究产出 (食伤) → 必须看食伤是否有力
   - 食伤旺：有想法、能出paper、主动性强
   - 食伤弱或被克：产出吃力、靠硬憋

2. 抗压持续力 (七杀/官) → 杀格的优势
   - 七杀格：高压实验室是舒适区
   - 正官格：需要稳定环境才能发挥

3. 录取/贵人运 (印) → 大运流年决定性因素
   - 印星到位年份：申请成功率大幅提高
   - 印星被合/被克年份：靠硬件硬拼

综合判断公式：
  PhD成功度 ≈ 食伤(产出) × 七杀(抗压) + 印(录取运)
```

### 4.3 学历阶段与大运的匹配

| 大运类型 | 对学业的影响 | 应对策略 |
|---------|-------------|---------|
| 印运 (水) | 最利学历，考试顺，贵人多 | 冲最好的项目 |
| 比劫运 (木) | 帮身，能拼但需自己扛 | 靠实力说话 |
| 食伤运 (火) | 出活快但考试弱 | 多出论文，减少应试依赖 |
| 财运 (土) | 财坏印，不利考试 | 工作/创业可能优于读书 |
| 官杀运 (金) | 压力大，竞争激烈 | 靠硬成果破局，减少投机 |

### 4.4 案例分析：身弱七杀格 × 申博（示例）

**原局示例：** 乙木日主身弱，七杀格（用木忌金）
**大运：** 丁未（食神+偏财）
**当前：** 丙午年（伤官+食神）

| 时间 | 流年 | 十神 | 对申博的影响 |
|------|------|------|-------------|
| 2026-27 | 丙午/丁未 | 食伤 | 做研究出活快，适合积累论文 |
| 2028 | 戊申 | 正财+正官(藏印) | 表面不利但申藏壬水=暗中有贵人 |
| 2029 | 己酉 | 偏财+七杀伏吟 | 压力最大，不利申请 |
| 2030 | 庚戌 | 正官+正财 | 平平，凭硬成果说话 |
| **2031** | **辛亥** | **七杀+正印** | **印星到位，转机出现** |
| **2032** | **壬子** | **正印+偏印** | **水运最旺，申博最佳窗口** |

判断逻辑：即使大运不利学业（丁未财坏印），如果申请年份流年有印星到位，依然有胜算。核心策略是"食伤运出成果，印星年出手申请"。

## 五、大运评估的综合维度

### 5.1 不只是"好/坏"

评估一个大运需要多维度打标签：

```python
评估维度 = {
  "格局适配": "好/中/差",    # 是否匹配原局格局的路数
  "用神到位": 0-10分,        # 用神出现的比例
  "忌神程度": 0-10分,        # 忌神出现的比例
  "地支动荡": "合/冲/刑/害/无", # 是否动摇根基
  "体质影响": "有利/一般/消耗", # 对身体的实际影响
  "学术维度": "利/平/不利",   # 对考试/学历/研究的影响
}
```

### 5.2 丁未大运案例标签

以丁未大运（身弱乙木七杀格）为例：

| 维度 | 评分 | 说明 |
|------|------|------|
| 格局适配 | 差 | 食神生财对七杀格身弱不利 |
| 用神到位 | 2/10 | 只有未中藏乙木微根 |
| 忌神程度 | 7/10 | 丁火泄身、未土财生杀 |
| 地支动荡 | 丑未冲 | 日支被冲，根基不稳 |
| 体质影响 | 消耗 | 食神泄身+财坏印 |
| 学术维度 | 不利 | 财坏印，考试运打折 |

但"不利"不等于"做不到"——七杀格的人擅长在不利条件下破局。

## 六、分析时注意的通用陷阱

1. **格局不是命运的全部** — 七杀格不一定命苦，正官格不一定安稳
2. **身强/身弱决定策略** — 同样的格局，身强身弱分析完全相反
3. **大运流年要分开看** — 大运底色+流年应期=真实效果
4. **现代职业需重新映射** — 十神对应的古代职业（官=官员、财=商人）在现代要重新理解
5. **学历分析不可只看印** — 现代学术是研究产出(食伤)+录取(印)+抗压(杀)的综合
6. **给回答要结论优先** — 先说"能/不能/有机会"，再解释为什么
