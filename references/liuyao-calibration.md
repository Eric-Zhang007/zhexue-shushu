# 六爻脚本历法校准记录

`liuyao.py` 在起卦复核中先后发现 4 处 bug，已全部修复。本文记录修复内容、正确公式与验证基准，供校验脚本输出。

## Bug 1: 月干五虎遁错位 (off-by-one)

- 现象：2026-07-31（丙午年未月）输出 `丙未`，正确应为 `乙未`（丙年未月=乙未，五虎遁：丙年庚寅起 → 庚寅辛卯壬辰癸巳甲午乙未）
- 原因：`yue_gan_map` 数组以寅月为索引 0（丙年：庚寅、辛卯...），而 `get_solar_month_idx` 返回的 `solar_idx` 以寅月为 1（0=丑月）——差一位
- 修复：`yue_gan = yue_gan_map[year_gan_idx][solar_idx - 1]`；丑月时 solar_idx=0，Python 负索引 -1%12=11 自动取到丑月干 ✓
- 旁证：bazi.py 早有 `month_gan_correct` 用 `(start + solar_idx - 1) % 10` 处理同款错位；liuyao.py 是漏网的

## Bug 2: 旬空公式错误

- 现象：2026-07-31（丙午日）输出空 `午未`，正确应为 `寅卯`（丙午日在甲辰旬）
- 原因：原公式 `DI_ZHI[(ri_zhi_idx // 2) * 2 : +2]` 只按地支硬切，与日柱所在旬无关
- 修复：改用核心库 `zhexue_core.xunkong_ganzhi(gan_idx, zhi_idx)`（qimen/liuren 早已在用；qimen.py 里还有同名 workaround `correct_xunkong`）
- 正确算法（gap 法）：`gap = (zhi_idx - gan_idx) % 12`；`xun = {0:0, 10:1, 8:2, 6:3, 4:4, 2:5}[gap]`；空亡表 `XUN_KONG = {0:(10,11),1:(8,9),2:(6,7),3:(4,5),4:(2,3),5:(0,1)}`（甲子旬空戌亥，甲戌空申酉，甲申空午未，甲午空辰巳，甲辰空寅卯，甲寅空子丑）
- 等价公式（60 甲子序号）：`n = (6*gan - 5*zhi) % 60`，旬 = n // 10（0=甲子 1=甲戌 2=甲申 3=甲午 4=甲辰 5=甲寅），再查空亡表

## Bug 3: time_guaxiang KeyError

- 现象：`run.py liuyao time 2026 7 31 21` 报 `Error: 8`（KeyError）
- 原因：`num_to_gua[shang if shang != 0 else 8]`——dict 只有键 0-7（0 映射坤），键 8 不存在；(年+月+日)%8==0 时必炸（2026+7+31=2064 恰为 8 倍数）
- 修复：直接 `num_to_gua[shang]`（余数 0 已映射坤=先天数 8，注释已澄清）

## Bug 4: TRIGRAM_MAP 兑/巽、震/艮映射写反 (2026-08-16 修复)

- 现象：铜钱起卦输出"火风鼎"（离宫二世，世二应五），复核发现初爻、三爻阴阳符号是火泽睽的行位样式
- 根因：`TRIGRAM_MAP` 四行映射错误——
  - `(0,1,1)` 标成兑，实际是巽（巽下断：初阴二三阳）
  - `(1,1,0)` 标成巽，实际是兑（兑上缺：初阳二阳三阴）
  - `(0,0,1)` 标成震，实际是艮（艮覆碗：初阴二阴三阳）
  - `(1,0,0)` 标成艮，实际是震（震仰盂：初阳二三阴）
- 后果：凡本卦/变卦含兑、巽、震、艮任意一卦，行位→卦名识别全错。实际卦体是火泽睽（行位 [1,1,0,1,0,1] = 下兑上离），被误认成火风鼎，世应、纳甲、六亲、变卦全部跟着错——原解卦作废重排重解
- 修复：对照口诀"兑上缺、巽下断、震仰盂、艮覆碗"重写四行，加注释防回归
- 验证：`run.py liuyao manual 1 1 0 1 0 1 0 2 0 0 3 0` → 火泽睽（艮宫四世，世四应初），变卦天雷无妄；纳甲丁巳丁卯丁丑/己酉己未己巳 与手排一致
- 教训：复核时若发现"卦象表编码瑕疵"，不能只当显示问题——行位是卦体本身，先验证 TRIGRAM_MAP 再决定是否重排

## 变爻六亲口径（脚本约定）

- 脚本对变爻六亲一律按**变卦宫的五行**定（`liuyao.py`: `b_palace_wx = bian_gua['palace_wuxing']`）。六爻流派/软件存在按本卦宫定的另一口径；本工具统一采用脚本口径，**解读时不得手算另行改写**。
- 已验证实例（地火明夷 → 山火贲）：上爻癸酉父母动，变出丙寅；丙寅按变卦山火贲（艮宫，土）定六亲为**官鬼**——若按本卦坎宫口径会读成子孙，方向完全相反。这就是口径必须统一的原因。
- 同卦自检基准：地火明夷（坎宫游魂，世4应1），纳甲上卦癸丑/癸亥/癸酉、下卦己卯/己丑/己亥；戊子日旬空午未；六兽勾陈/螣蛇/白虎/玄武/青龙/朱雀（戊日起勾陈）。

## 流程教训

- 解卦/复核环节发现脚本输出与历法不合（干支不成对、旬空可疑）时，先修脚本再解读，不要带着错误数据往下走
- 每次修历法相关逻辑后必须回归上表，尤其是边界日期
