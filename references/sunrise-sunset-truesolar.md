# 真太阳时 & 日出日落法时辰判定

## 背景

真太阳时和日出日落法是命理界争议较大的时辰修正方法。本参考整理本次会话中验证的完整计算流程。

---

## 一、真太阳时（标准法）

### 原理

将手表（北京时间/UTC+8）修正为本地真实太阳位置。

### 两步修正

**第一步：经度修正**
北京时间用东经120°线。每偏1° = 4分钟。

```
本地平均时 = 北京时间 + (本地经度 - 120) × 4分钟
```

例如北京（东经116.40°）：
```
(116.40 - 120) × 4 = -22.08分钟
北京时间12:00 → 本地平均时11:44
```

**第二步：均时差（Equation of Time）修正**

地球轨道为椭圆，太阳视运动不均匀，每年各日需修正：

| 日期 | 均时差 | 说明 |
|------|--------|------|
| 2月中旬 | ~-14min | 太阳比钟慢 |
| 5月中旬 | ~-3min | 接近平衡 |
| 7月下旬 | ~-6min | 太阳比钟慢 |
| 9月下旬 | ~+8min | 太阳比钟快 |
| 11月初 | ~+16min | 太阳比钟快（最大） |

**完整公式：**
```
真太阳时 = 北京时间 + (本地经度 - 120) × 4 + 均时差(分钟)
```

### 常用三档

| 方法 | 操作 | 使用人群 |
|------|------|---------|
| 北京时间不调 | 直接用 | 很多人（"你妈看的是手表"） |
| 经度修正 | 只调经度 | 最大多数人 |
| 经度+均时差 | 两步全调 | 少数追求精确者 |
| 日出日落法 | 见下 | 极小众 |

---

## 二、日出日落法（别名：日照比例法）

### 原理

以当天日出=卯时、日落=酉时为锚点，将白昼和黑夜各平分为6段，每段=一个时辰。时辰长度随季节变化（夏长冬短）。

### 计算步骤

**步骤1：获取精确日出日落时间**

使用天文库（ephem）而非简化公式（`cos⁻¹(-tan φ tan δ)` 不考虑大气折射）。

```python
import ephem
from datetime import datetime, timedelta

obs = ephem.Observer()
obs.lat = '39.90'       # 纬度（度）
obs.lon = '116.40'      # 经度（度）
obs.date = '1986/03/15' # 日期

sun = ephem.Sun()
sunrise = obs.next_rising(sun)
sunset = obs.next_setting(sun)

# 转为北京时间（UTC+8）
def utc_to_bjt(d):
    t = d.datetime() + timedelta(hours=8)
    return t

print(utc_to_bjt(sunrise))  # 日出（BJT）
print(utc_to_bjt(sunset))   # 日落（BJT）
```

**步骤2：计算昼夜分段**

```
昼长 = 日落 - 日出
夜长 = 24h - 昼长

每个白昼时辰长度 = 昼长 / 6
每个黑夜时辰长度 = 夜长 / 6
```

**步骤3：时辰映射**

- 白昼6时辰：**辰巳午未申酉**（日出=卯时末/辰时始）
- 黑夜6时辰：**戌亥子丑寅卯**（日落=酉时末/戌时始）

### 注意事项

- ephem 自动计入大气折射，结果比简化公式偏早2~3分钟（日出更早，日落更晚）
- 边界时辰（如戌亥交界）需精确计算到分钟
- 此方法极小众（无统一祖师文献），主流命理界基本不用

## 三、实践案例

### 案例：1986-03-15 12:00 北京（39.90°N, 116.40°E）

**精确天文数据（ephem）：**
```
日出：6:14:55 (BJT)
日落：18:11:14 (BJT)
真太阳时正午 (BJT)：12:12:36
```

**经度修正：**
```
北京经度116.40°E
北京时间12:00 → 本地平均时11:44
```

**日出日落法分段：**
```
昼长 6:15~18:11 = 11h56min → 每白昼时辰 ≈ 119min
夜长 18:11~次日6:15 = 12h04min → 每黑夜时辰 ≈ 121min

辰：06:15~08:14
巳：08:14~10:14
午：10:14~12:13
未：12:13~14:12
申：14:12~16:11
酉：16:11~18:11

戌：18:11~20:12
亥：20:12~22:13
子：22:13~00:14
```

**结论：12:00 → 午时**
- 固定时辰法（标准）：午时（11:00-13:00）
- 日出日落法：午时
- 两种方法结论一致

### 边界情况

如果出生时间在边界附近（如12:10在北京9月），则：
- 固定法：午时
- 日出日落法：午时（差2分钟到未时）

**遇到边界情况时，优先采用固定时辰法**，因为日出日落法在命理界非常规做法。

## 四、技术要点

| 要点 | 说明 |
|------|------|
| 用 ephem 而非公式 | 简化公式误差可达3~5分钟（因忽略大气折射） |
| 只验证不盲信 | 用户可能会自己查到不同的日出日落数据，以天文库计算结果为准 |
| 不做定论 | 日出日落法在小众流派内部也无统一标准（时辰起点是日出还是日出前半小时？），分析时需说明"按此方法则..." |
| 时辰不变优先 | 如果两种方法结果一致，直接确认；如果不一致，明确指出分歧、给出边界时间，由用户判断 |
