# 紫微斗数分析方法体系

## 分析流程（排盘完成后）

### 第一步：命宫核心格局
**三要素：主星 + 四化 + 辅星**

- 命宫主星决定了"你是谁"的底色
- 生年四化落在命宫 → 放大该星特性（尤其化忌和化禄）
- 凶星同度（陀罗、擎羊、火星、铃星）会改变主星表现
- 天马在命宫 = 思维/生活状态不稳定，好动

**四化通用解读：**
- 化禄 = 该宫位天生有资源/福气，不需刻意追求
- 化权 = 该宫位要你主动掌控，不能放任
- 化科 = 该宫位有"文墨贵气"，名声/智性层面的增益
- 化忌 = 该宫位是你一生的功课，付出多但成长也最大

### 第二步：身宫定归宿
身宫是你人生的"落脚点"——中年以后（40+）会越来越像这个宫位。
- 身宫在命宫 → 一生靠自己，自我意识最强
- 身宫在福德宫 → 精神世界是你一生的归宿
- 身宫在夫妻宫 → 婚姻/伴侣关系定义你的人生
- 身宫在财帛宫 → 经济能力是你的安全感来源
- 身宫在官禄宫 → 事业成就定义你
- 身宫在迁移宫 → 在外发展/异乡成就是你的人生路径

**重点：** 身宫和命宫的星曜共同作用，命宫是"出厂设置"，身宫是"升级方向"。

### 第三步：四化线索网
生年四化（固定）+ 飞宫四化（宫干引发）→ 形成"化出化入"的能量流向。

核心规则：
- 化禄入某宫 = 该宫轻松得到资源
- 化忌入某宫 = 该宫需要你付出，是最弱的突破口
- 化禄+化忌 = 给两分拿走一分，入不敷出
- **命宫化忌对宫（疾厄宫）= 精神消耗直转身体消耗**

### 第四步：逐宫分析

**十二宫分析优先级（按权重递减）：**

1. **命宫** — 底色（巨细无遗看星组）
2. **身宫所在宫位** — 归宿（如果是命宫则跳过）
3. **夫妻宫** — 亲密关系模式（尤其化禄/化忌）
4. **迁移宫** — 出外发展、贵人运、社交风格
5. **官禄宫** — 事业模式、成就感来源
6. **财帛宫** — 金钱观、收入模式
7. **福德宫** — 精神世界、内心冲突
8. **疾厄宫** — 健康状况、身心关联
9. **父母宫** — 原生家庭、权威关系
10. **田宅宫** — 家庭状态、底层安全
11. **兄弟宫** — 朋友、同辈、竞争者
12. **子女宫** — 子女缘、创造力

**每一宫的星曜解读框架：**
- 主星（这张脸的基调）
- 辅星（修饰或扭曲）
- 杂星（小细节，也重要）
- 四化（能量方向）
- 对宫（站在对面看这宫，往往更准）
- 三方四正（三合宫+对宫，全局关联）

**庙旺利陷：** 同样一颗星在不同地支亮度和力量不同。
- 庙/旺 = 正面发挥，能量强
- 平/得 = 中等水平
- 不/陷 = 负面表现，力量弱

### 第五步：大限与时间维度

**大限（每宫10年）：**
- 阳男阴女 → 顺行（命宫→父母→福德→田宅→...）
- 阴男阳女 → 逆行（命宫→兄弟→夫妻→子女→...）
- 命宫起始岁 = 五行局数（火六局→6岁起运）
- 每个大限的宫位决定了那个10年的人生重心
- 大限宫位里的星曜 + 四化 = 那十年的主旋律

**三限叠加法：**
1. 本命盘（先天底色）
2. 大限盘（10年趋势）
3. 流年（当年应期）

**流年看几个关键：**
- 流年命宫与大限命宫重合的年份（应期最强）
- 流年禄/忌入哪个宫位
- 流年小限与大限的重叠

### 第六步：综合结论框架

给出分析结论时，至少覆盖以下层面：

1. **一句话核心格局**（如"你是暗室磨刀之格，深度思考型"）
2. **当前阶段的人生主题**（如"16-25岁父母宫大限，借权威体制的资源走自己的路"）
3. **最强的宫位和最弱的宫位**（迁移宫强 vs 疾厄宫弱）
4. **关键关系模式**（夫妻宫、兄弟宫、交友宫的综合判断）
5. **事业方向建议**（基于官禄宫+迁移宫+命宫的综合判断）
6. **时间节奏**（什么时候是人生转折期、什么时候是大运节点）

## 全局关联要点

- **命宫无主星** → 对宫借星（迁移宫主星影响命宫）
- **空宫（旬空+截空）多次出现** → 这条路不是常规路线，需跳出框架思考
- **禄权科忌四化同一宫** → 超级强宫，人生制高点
- **六煞星（擎羊陀罗火星铃星地空地劫）两星以上同宫** → 该宫位有重大冲突或挑战
- **华盖在福德/命宫** → 与形而上有缘，独立不入流
- **天才+天机科** → 在朋友中被当聪明人用

## 常见分析错误

1. **只列星不连** — 紫微分析不是列清单，是看星与星、宫与宫之间的关联
2. **忽略对宫** — 每个宫的分析必须看对宫（如夫妻宫要看官禄宫）
3. **不区分本命和大限** — 先天盘和后天盘是两套不同的系统
4. **对四化只看"好"和"坏"** — 化忌不等于惨，化禄不等于一帆风顺
5. **用命理做规训** — "你这样会离婚/会缺钱"不是分析，是迷信

---

> 最后：紫微斗数是"倾向学"不是"因果学"。命盘画出的是底纹和概率，不是必定的剧本。任何分析的最终出口必须是"主动权在你"。
